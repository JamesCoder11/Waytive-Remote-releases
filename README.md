# Waytive Remote

공식 설치 파일과 Sparkle 업데이트 피드를 제공하는 **배포 전용 저장소**입니다. 애플리케이션 소스 코드는 이 저장소에 포함하지 않습니다.

Waytive Remote는 등록한 내 Mac에 연결해 여러 화면을 보고 키보드와 마우스로 제어하는 macOS 앱입니다. 같은 네트워크 또는 서로 접근 가능한 VPN 주소를 사용하는 Mac 간 연결을 위한 개발 프리뷰입니다. 인터넷 NAT 통과·중계는 제공하지 않습니다.

## 다운로드와 설치

**연결하는 두 Mac 모두 0.2.0이 필요합니다.** 이전 버전과의 원격 연결은 지원하지 않습니다.

1. 배포 확인 표의 0.2.0 릴리스 페이지에서 `Waytive-Remote-0.2.0.zip`을 내려받아 압축을 풉니다.
2. 기존 앱을 사용 중이면 원격 연결을 종료하고, 두 Mac의 Waytive Remote를 종료합니다.
3. 압축을 푼 `Waytive Remote.app`을 응용 프로그램 폴더로 옮깁니다. 기존 앱이 있으면 새 앱으로 교체합니다.
4. 두 Mac에서 0.2.0을 실행합니다. 대상 Mac의 공유 설정에서 화면 공유를 켜고 화면 기록 권한을 허용합니다. 키보드·마우스 제어에는 손쉬운 사용 권한도 필요합니다.
5. 대상 Mac에서 만든 등록 링크를 연결할 Mac에 등록합니다. 두 Mac은 같은 네트워크 또는 VPN을 통해 서로 접근할 수 있어야 합니다.

macOS 보안 설정이나 앱·업데이트 서명 검증을 해제하지 마세요. 등록 링크에는 접속 권한이 포함되므로 본인 소유의 기기에만 전달해 주세요.

## 0.2.0의 주요 기능

- **여러 디스플레이:** 원격 Mac의 화면을 실제 배치에 맞춘 전체 보기에서 확인하고, 원하는 화면만 선택해 크게 봅니다. 모델명·해상도·주사율·주 디스플레이 정보를 표시합니다.
- **전체 화면 도구 막대:** 자동 숨김·가장자리 손잡이·위치 이동·항상 표시를 제공합니다. 항상 표시를 켜면 원격 화면 바깥에 고정합니다.
- **단축키:** `⌃1`~`⌃9`로 화면을 전환하고 `⌃0`으로 전체 보기를 엽니다. `⌃⌥T`로 도구 막대를 열고, `⌃⌘F`로 전체 화면을 전환하며, `⌘⌥Esc`로 원격 제어를 해제합니다.
- **코덱·화질:** 연결 시 양쪽 지원 목록에 맞는 코덱을 선택합니다. HEVC·H.264를 사용할 수 없는 조합에는 JPEG 경로를 제공합니다. 최대 프레임은 30·60·120fps 중 선택합니다. 원격 해상도 자동 맞춤·창에 맞춤·원본 크기(1:1)·부드러운 스케일링을 제공합니다.
- **Retina·4:4:4:** 새 기기 설정의 Retina 해상도 기본값은 켬이며, 이미 저장한 켬·끔 선택은 유지합니다. 4:4:4는 호스트의 4:4:4 인코딩과 뷰어의 4:4:4 디코딩 지원이 모두 확인된 코덱 조합에서만 활성화합니다. 코덱 자체를 지원해도 4:4:4는 지원하지 않을 수 있습니다.
- **입력:** 특수 키 보내기·키 매핑·상대 마우스 모드·보기 전용·가운데 버튼·가로 스크롤을 제공합니다.
- **파일·클립보드:** 파일 보내기·받기·드래그 앤 드롭 업로드와 텍스트 클립보드 양방향 동기화를 제공합니다. 받은 파일은 `~/Downloads/Waytive Remote`에 저장합니다.
- **설정·통계:** 기기별 설정 저장과 시스템·라이트·다크 화면 모양을 제공합니다. 왕복 지연·수신 영상 프레임 수·수신 앱 데이터 속도(Mbps)·코덱을 표시합니다.

최대 프레임 설정은 실제 전송 속도를 보장하지 않습니다. 화질과 프레임 수는 디스플레이·하드웨어·네트워크 상태에 따라 달라집니다. 통계의 fps는 수신 영상 메시지 기준이며 렌더링 완료 프레임 수가 아닙니다. Mbps에는 파일·제어 데이터와 앱 메시지 길이 접두도 포함되며, TLS 오버헤드와 실제 링크 전체 사용량은 포함하지 않습니다.

## 0.1.22에서 달라진 점

- 세 가지 화질 프리셋 대신 코덱·최대 프레임·Retina·4:4:4·스케일링을 개별 설정합니다. 기존 절약 모드의 1920px 프리셋은 제공하지 않습니다.
- 모니터 선택과 전체 화면 전환을 분리했습니다. 화면을 고른 뒤 전체 화면 버튼이나 `⌃⌘F`로 전환합니다.
- 업데이트 배지는 기기 화면에만 표시합니다. 세션 제목 줄·전체 화면 도구 막대에는 표시하지 않습니다.
- 원본 크기(1:1) 보기, Caps Lock 입력 소스 전환, 로컬 화면 전환·제어 해제 단축키와 저장된 기기·세션 설정은 유지합니다.
- 이전 세션 UI의 일부 접근성·자동화 식별자는 새 디스플레이 번호와 개별 설정 기준으로 바뀌었습니다.

### 정지 화면 보정과 오류 복구의 검증 범위

0.1.22의 정지 화면 PNG 무손실 보정 대신 **같은 코덱의 고품질 키프레임 보정**을 사용합니다. 고품질 키프레임을 만드는 미디어 컴포넌트와 이후 정상 프레임 복구는 합성 영상으로 확인했습니다. 이는 무손실 전송이 아닙니다. 한 화면 보기에서 화면 변화가 **0.4초 동안 멈추면 보관한 최신 프레임으로 보정을 보내는 호스트 연결**을 완료하고 자동 시험으로 확인했습니다. 실제 GUI의 정지 화면 화질은 아직 측정하지 않았습니다.

정지 화면의 키프레임 즉시 재전송, 디코더 burst 처리, 뷰어 키프레임 요청 지연 보존, 연결 후 자동 제어 시작·비활성화 시 제어 의도 보존, 연결 중 `⌘N` 기기 등록 차단은 구현·컴포넌트 시험으로 확인했습니다. 실제 키보드·VoiceOver·포커스 복귀와 정지 화면 GUI E2E 전체를 검증한 결과는 아닙니다.

인코딩 실패 시 해당 화면에서 **호스트 인코딩·뷰어 디코딩 지원 코덱의 교집합 안에서 한 번 대체**하고 안내합니다. 상대가 코덱 지원을 광고하지 않으면 JPEG만 대체 후보로 삼습니다. 다음 공통 지원 코덱이 없거나 대체 후 두 번째로 실패하면 연결을 종료합니다. 이 분기는 자동 시험으로 확인했으며 모든 인코더 오류를 JPEG로 무조건 복구하거나 실제 VideoToolbox 장애를 모두 검증했다는 뜻은 아닙니다.

## 확인한 검증과 한계

- **로컬 코덱:** 합성 영상으로 HEVC·H.264·JPEG 인코딩→디코딩 왕복, 키프레임 복구, 크기·코덱 변경, 고품질 보정과 정상 프레임 복구를 확인했습니다. 현재 검증한 하드웨어의 4:4:4 비트스트림과 디코딩도 확인했지만 모든 Mac의 지원을 증명하지는 않습니다.
- **같은 Mac의 loopback:** Developer ID로 서명한 0.2.0 리허설 앱 두 개로 실제 화면 캡처→HEVC→TLS→디코딩→표시 경로를 1회 확인했습니다. 50프레임과 당시 왕복 지연 17.8ms를 관측했습니다. 같은 Mac의 짧은 관측이며, 서로 다른 두 Mac이나 지속 성능의 검증은 아닙니다. 최종 배포 앱으로도 같은 연결을 1회 다시 확인했습니다(HEVC 표시, 당시 왕복 지연 10.5ms, 연결 종료 시 입력 해제·해상도 복구 호출 기록 확인).
- **로컬 해상도 복구:** 주 디스플레이가 아닌 외부 디스플레이 한 대의 해상도 변경·즉시 복구를 확인했습니다. 실제 두 Mac 세션 종료, 강제 종료·전원 단절 시 복구까지 검증한 결과는 아닙니다.
- **아직 검증하지 않은 항목:** 서로 다른 Mac 두 대의 실제 제어, 실제 데스크톱 키·마우스 주입과 상대 커서 고정, 실제 캡처에서 120fps 지속 동작, 여러 하드웨어의 4:4:4 지원 범위, HiDPI·회전 화면 실물 호환성입니다. 파일 드롭·호스트 선택 창·VoiceOver를 포함한 전체 UI E2E 및 macOS 14 실기기 실행도 별도 검증이 필요합니다. 합성 피어·오프스크린 UI 시험을 이 항목들의 실물 통과로 보지 않습니다.
- **아직 확인하지 않은 배포 항목:** 공개 구버전 앱의 수동 설치 안내·링크 열기, 새 키 경로의 실제 다운로드·교체·재실행, 0.4초 정지 화면 보정의 실제 GUI 화질입니다.
- **지원하지 않는 기능:** 인터넷 NAT 통과·중계, Windows, 오디오 전송, 로그인 화면 제어, 이미지·리치 텍스트 클립보드입니다.
